To see the list of branches (which are available in local)
git branch

To see the list of branches available in remote (i.e GitHub)
git branch -r

To see the list of all branches available in local and also in GitHub
git branch -a

To see the number of branches in remote repo
git branch -r |wc -l
You will see the count of branches in GitHub
