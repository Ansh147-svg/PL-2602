=> Types of Docker Images;

	2. Child Images

Using Dockerfile we will build the image, that image is known as Child Image

RUN apt update -y && apt install git -y

Types of Base Images;
Standard Images
	Size: Large (300 MB - 1 GB+)
	Content: Full OS with package manager, build tools, libraries...
	Ex: ubuntu:22.04, python:3.10, node:25

Slim Images
	Size: Medium (50 MB - 150 MB)
	Content: Minimal OS, basic utilities, no build tools
	Ex: python:3.10-slim, node:25-slim

Alpine Images
	Size: Small (5 MB - 50 MB)
	Content: Alpine Linux, apk
	Ex: python:3.10-alpine, node:25-alpine

Distroless Images
	Created by Google
	Size: Very Small (2 MB - 30 MB)
	Content: Only application run time, no shell, no package manager
	Ex: gcr.io/distroless/python3.10

Scratch Images
	Size: 0 MB	
	Content: Absolutely empty, No shell, No OS, nothing...
	
 cat Dockerfile.standard
FROM python:3.11
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY app.py .
EXPOSE 5000
CMD ["python", "app.py"]

cat Dockerfile.slim
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY app.py .
EXPOSE 5000
CMD ["python", "app.py"]

cat Dockerfile.alpine
FROM python:3.11-alpine
WORKDIR /app
RUN apk add --no-cache gcc musl-dev
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY app.py .
EXPOSE 5000
CMD ["python", "app.py"]
