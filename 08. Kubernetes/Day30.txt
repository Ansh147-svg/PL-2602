=> RBAC
Roll Based Access Control

ServiceAccount
Role
Role Binding


| Verb               | Purpose                                                               |
| ------------------ | --------------------------------------------------------------------- |
| `get`              | Read a specific resource                                              |
| `list`             | List multiple resources                                               |
| `watch`            | Watch for resource changes in real time                               |
| `create`           | Create a new resource                                                 |
| `update`           | Modify an existing resource                                           |
| `patch`            | Partially update a resource                                           |
| `delete`           | Delete a resource                                                     |
| `deletecollection` | Delete multiple resources at once                                     |
| `proxy`            | Access resource via proxy                                             |
| `use`              | Use specific resources (mainly Pod Security Policies / special cases) |
| `bind`             | Bind roles to subjects                                                |
| `escalate`         | Create/modify roles with permissions you may not already have         |
| `impersonate`      | Act as another user, group, or service account                        |
| `approve`          | Approve certificate signing requests (CSR)                            |
| `sign`             | Sign certificates                                                     |
| `renew`            | Renew leases/certificates                                             |
