Terraform is used to automate the infrastructure creation
Infrastructure - Instances, VPCs, IAM Users/Roles, S3 Buckets....
Terraform is infrastructure automation tool

Pulimi and OpenToFu

Using Terraform we can create the infra in any cloud
Terraform is cloud independent

AWS - Cloud Formation
GCP - Deployment Provider
Azure - Azure Resource Manager

HCL - Hashicorp Configuration Language

Any terraform files will have ".tf" as an extension

provider.tf**
version.tf**
main.tf
variables.tf
terraform.tfvars
output.tf

terraform.tfstate

terraform init		- initialize the terraform - terraform downloads the provider plugins - Provider (AWS/GCP/Azure)
terraform validate	- it will verify whether the syntax is valid or not
terraform fmt		- it will arrange the structure of terraform file in a decent way (aligning)
terraform plan	- terraform will analyze all the .tf files in the current location and then it will tell us what resource(s) will get created when we run the code
terraform apply	- actual resource will get created
terraform destroy	- the resources which are created using terraform will get destroyed
