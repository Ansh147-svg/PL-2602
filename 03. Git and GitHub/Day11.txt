=> Recovering a deleted file
Case 1: deleted the file, but not staged
git restore hello.txt (or) git checkout -- <FileName>

Case 2: deleted the file, and staged as well, but not committed
git restore --staged hello.txt
git restore hello.txt

Case 3: deleted the file, staged as well and committed also
git restore --source=209d0f5 -- hello.txt
