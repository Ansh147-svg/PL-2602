=> Repositories concept
We can create two types of repos based on visibility;
	1. Public Repo	- anything that we keep in this can be accessed by anyone on the internet
	2. Private Repo	- anything that we keep in this cannot be accessed by anyone, until explicit permissions are provided

For every repo, we will get unique repo URL
