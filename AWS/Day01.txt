Cloud Computing Models - How and where to deploy

1. Service based models - IaaS, PaaS, SaaS
On-premises: everything has to be managed by the organization
IaaS - Cloud (Servers, Storage, Networking, Virtualization), You (OS, Middleware, Runtime, App)
PaaS - Cloud (Servers, Storage, Networking, Virtualization, OS, Middleware), You (Data, App)
SaaS - Cloud (Servers, Storage, Networking, Virtualization, OS, Middleware, Data, App), You (Code)

2. Deployment based models - Public, Private, Hybrid, Community
Public Cloud - Bus - Accessible to everyone (AWS, Azure, GCP) - pay as you go / pay as you use
Private Cloud - Car - Accessible to specific companies (IBM Cloud) - high cost / huge up-front cost
Hybrid Cloud - Taxi - Public Cloud + Private Cloud - Not so costly - pay as you go / pay as you use
